Glowly — Skincare Application

Project Overview

Glowly is an academic project developed as part of the Software Engineering Fundamentals course at Umm Al-Qura University. It proposes a skincare application designed to help users manage their skincare routines and explore products based on their skin types and concerns.

Project Work

* Identified the problem and defined the project scope.
* Documented functional and non-functional requirements.
* Developed user stories and use case descriptions.
* Designed use case, sequence, and class diagrams.
* Defined the proposed client-server architecture.

Project Information

* Course: Software Engineering Fundamentals
* Project Type: Academic Project
* Focus: Requirements Analysis and System Design

Project Status: Requirements analysis and system design completed. Application implementation was not part of the completed work.
